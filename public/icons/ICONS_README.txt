ICON PLACEHOLDERS — REPLACE BEFORE GOING LIVE

Place the following icon files in this directory (public/icons/):

1. icon-192.png  — 192×192 pixels PNG
2. icon-512.png  — 512×512 pixels PNG

These are required for PWA installation.

Guidelines:
- Use a simple printer icon or company logo
- Icons should work on both light and dark backgrounds
- Mark as "maskable" (safe zone = center 80% of the image)
- Background color should match manifest.json "background_color" (#f8fafc)

You can generate icons using:
- https://maskable.app/editor (free, browser-based)
- https://realfavicongenerator.net (free, all sizes)
- Any image editor (Canva, Photoshop, etc.)

Until real icons are created, the browser will show a default icon.
